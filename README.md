# Moodify Sync 🎵

Full-stack app with:
- Frontend (React / Next.js)
- Backend (Node.js / Express)

## 📁 Project Structure

/moodify-sync-client → deployed on Vercel  
/moodify-sync-server → deployed on Render  

## 🚀 Live Links

 https://moodify-sync-omega.vercel.app

## ⚙️ Setup

### Clone
git clone ...

### Frontend
cd moodify-sync-client
npm install
npm run dev

### Backend
cd moodify-sync-server
npm install
npm run dev
